# Air-Canvas
Air Canvas

Air Canvas is a computer vision-based virtual drawing application that enables users to draw on a digital canvas using real-time hand gestures captured through a webcam. Instead of relying on a mouse, stylus, or touchscreen, the system tracks a colored object or the user's fingertip and translates its movement into smooth digital strokes. By leveraging Python, OpenCV, and image processing techniques, Air Canvas provides a touch-free, interactive drawing experience with multiple color options, brush controls, and canvas clearing functionality. The project demonstrates the practical application of computer vision and gesture recognition in creating intuitive human-computer interaction systems, making it suitable for educational purposes, virtual whiteboards, creative sketching, and contactless user interfaces.

Key Features

🎨 Real-time virtual drawing using hand gestures
📷 Webcam-based object/fingertip tracking
🌈 Multiple brush color selection
🖌️ Smooth drawing with adjustable brush thickness
🧹 One-click canvas clearing
⚡ Fast and responsive computer vision processing
💻 Cross-platform support using Python and OpenCV
